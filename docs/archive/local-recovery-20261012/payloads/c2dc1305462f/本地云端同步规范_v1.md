# 算法仓库本地—云端同步规范 v1

适用仓库：`D:\Project\厚粲杯\08_算法` 及其登记的 Git worktree。

## 固定身份

- canonical remote: `https://github.com/greenboo26/focuswave-multimodal-attention-analysis.git`
- canonical integration branch: `main`
- `master` is a parallel historical branch; do not treat it as the current integration entry or merge it automatically during file organization.
- 当前工作分支必须在任务记录中说明用途、上游分支和本地路径。
- `main`、`master`、`codex/*`、`sample/*` 不得因整理文件夹自动创建或重命名。

## 分支与路径

1. 有现成授权分支时优先复用，不为临时分析新建分支。
2. 一个分支只能有一个活动 checkout；多个 checkout 必须由 `git worktree list` 登记。
3. 已删除远程分支只标记为 `gone`，先保留本地提交和工作树，确认无独有证据后才能归档或删除。
4. 目录移动前必须记录旧路径、新路径、分支、HEAD、文件数和字节数；活动 worktree 不得用普通文件移动操作搬迁。

## 同步与验收

1. 先 `git fetch --all --tags`，再比较本地 HEAD、远端 HEAD 和工作树状态。
2. 常规同步只允许 fast-forward；分叉、远端落后、本地领先和 `gone` 必须分别报告。
3. 不得使用 `reset --hard`、`clean -fd`、force push 或覆盖未提交用户修改来制造“同步完成”。
4. 推送后必须重新读取远端 commit SHA；本地 commit、fetch 成功和远端 push 是三个不同证据。
5. 结果、原始数据、虚拟环境、缓存、模型缓存和认证材料不进入代码仓库。

## 最小记录字段

`repository_path`、`remote_url`、`local_branch`、`upstream`、`local_head`、`remote_head`、`ahead_behind`、`worktree_clean`、`active_worktree_path`、`verified_at`。
